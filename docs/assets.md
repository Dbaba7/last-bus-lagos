# Assets and map

All visible arena models, player/weapon models, signs, UI layout, favicon and synthesized sounds were created in code for this prototype. No ripped models, celebrity likenesses, brand marks or remote asset URLs are used. **The game currently contains no commercial music.** The only music is original and generated by the game. The arena is a fictional composition inspired by Lagos streets; it is not a surveyed reconstruction of Ojuelegba.

| Asset group | Source | Notes |
| --- | --- | --- |
| Buildings, shutters, stalls, cover, utility poles | `apps/client/src/world.ts` | Procedural boxes and original storefront names |
| Yellow minibuses | Same | Generic danfo-inspired forms; no manufacturer branding |
| Arena and spawn geometry | `packages/shared/src/world.ts` | Shared server collision and client cover dimensions |
| Team characters and weapon presentation | Client world/renderer | Original low-poly block geometry; Gold/Teal silhouettes |
| Signs | Canvas dynamic textures | System sans-serif; no downloaded fonts |
| Audio | `apps/client/src/audio.ts` | Oscillators for cues/footsteps; generated noise for soft ambience |
| Radio music | `apps/client/src/soundtrack.ts` | "Danfo Groove", an original 90-second placeholder rendered by the game at run time; no sample or file |
| Licensed music | `apps/client/src/music/` (not in the repo) | Empty. The folder is in `.gitignore`. Nothing goes in it until a licence is signed |
| Menu/HUD/icon | Client CSS/HTML and `public/favicon.svg` | Original code-native assets |

The compact 64 × 48 m arena has a central bus route, narrow lanes beside the arcades and outer market flanks. Solid storefronts restrict direct routes; spawn dividers break central sightlines. Spawn selection rewards distance and occlusion and discourages occupied friendly positions. Every configured spawn has automated collision clearance. The map still needs a human 4–8-player balance session and cultural/art-direction review.

Collision uses simplified solid AABBs. Small decorative trim, wheels, awnings and cables do not have independent collision. There are no enterable building interiors, crouch, climbing or drivable vehicles.

A commercial track can only play once its entry in `TRACKS` has `licensed: true` and a `src`, its file is in `apps/client/src/music/`, and the player has the Licensed music setting on. Until all three hold, the placeholder plays. Setting `licensed: true` is a statement that the master and composition rights are signed for game use; don't set it for anything else. No song lyrics appear on screen.

Runtime dependency licenses and notices are bundled at `/THIRD_PARTY_NOTICES.txt`, generated by `npm run licenses` from the lockfile and installed packages. Babylon.js carries Apache-2.0 terms and its NOTICE; Colyseus packages use MIT licenses. Dependency notices are separate from ownership of the original game code/art; no public license was assigned to the user's original project.
